# 投资手记 v2

在 Windows 双击 `run_investment.bat`，或在本目录运行 `python -m investment_tracker.server`，然后访问 http://127.0.0.1:8766。停止服务按 Ctrl+C。需要 Python 3.10 或更高版本；Excel 导出需安装 openpyxl。

v2 使用创建时从原账本复制的独立快照，数据位于 v2/data/investments.db，之后与原版本分别保存。停止服务后可复制该数据库备份。

在“模型分析”填写兼容 OpenAI Chat Completions 的 HTTPS 基础地址、模型名称和 API Key。DeepSeek 示例地址为 https://api.deepseek.com，模型可填写 deepseek-v4-flash。Key 不保存，刷新页面需要重新输入。

点击生成后，页面所列的持仓、账户汇总、报价时间和对应期间交易信息会发送到所选服务商。当天分析从当天零点开始，周报从本周一零点开始，截至生成时刻。模型只看到当前报价和交易节点的账本快照，不包含连续历史行情或实时新闻；结果仅供参考。

左侧“模型与投资偏好”统一设置模型、Key、计划持有月数、可承受最大回撤、单标的仓位上限、最低现金比例和其他偏好。设置（不含 Key）保存在当前浏览器，Key 只保留到页面关闭或刷新。单标的分析使用该标的最近 90 天交易及账户汇总，每日和每周分析共用这些偏好。最大回撤是用户设定的风险阈值，不能用现有交易节点代替连续行情计算实际最大回撤。

单日盈亏按昨日收盘价、当日报价和今日买卖现金流计算，包含手续费及余额宝当日模拟利息。行情缺失、非当日报价或报价早于交易时显示数据不足；金价可在手动更新价格时同时填写昨收价。目标仓位在持仓表中设置，总和不超过 100%。模型走势和买卖节点仅为条件性情景，缺乏充分行情时无法可靠给出价位。
